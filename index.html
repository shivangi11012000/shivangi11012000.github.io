BugBubble

A floating debugger inside your React Native app. It captures network calls, WebSocket events, console logs and analytics as they happen, so you can inspect a build on a real device with no cable and no laptop.

  • One component, zero configuration
  • Search and filter every log type
  • Draggable bubble, TypeScript types included
  • Choose what to track: network, WebSocket, console, analytics
npm install @lokal-dev/react-native-bugbubble 
import { BugBubble } from '@lokal-dev/react-native-bugbubble';

export default function App() {
  return (
    <>
      <YourAppContent />
      <BugBubble />
    </>
  );
}
